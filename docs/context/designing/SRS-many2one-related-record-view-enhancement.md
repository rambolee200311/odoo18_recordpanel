## 1 业务背景与目标

### 1.1 业务背景

Odoo 标准 Many2one 已经提供成熟的关联记录选择和打开能力。普通业务场景应继续使用官方默认行为，本项目不替代、不包装、不修改该默认能力。

在对账、审核、匹配和来源单据核对等场景中，用户选定关联记录后，经常需要同时查看当前业务记录和关联记录的关键数据。如果只能通过页面跳转、弹窗或临时提示查看关联记录，用户必须反复切换上下文，容易降低核对效率并增加判断成本。

本项目为明确需要增强的 Many2one 字段提供关联记录查看增强能力，使用户可以在不离开当前业务页面的情况下持续查看关联记录，或在新浏览器标签页打开完整关联记录。

### 1.2 当前问题

- 打开完整关联记录可能替换当前业务页面，导致用户丢失当前处理上下文。
- 弹窗、Tooltip 或临时提示不适合持续比较两条记录的数据。
- 不同关联模型需要展示的关键字段不同，固定展示一组字段无法满足不同业务场景。
- 关联记录预览不应变成第二个可编辑业务表单，否则会扩大操作范围和业务风险。

### 1.3 业务目标

- 目标 1：让用户可以在不离开当前业务页面的情况下持续查看关联记录的关键业务信息。
- 目标 2：让用户可以在新浏览器标签页打开完整关联记录，同时保留当前业务页面。
- 目标 3：让配置管理员可以按关联模型维护预览字段及其展示顺序。
- 目标 4：保证未使用增强能力的 Many2one 继续保持 Odoo 官方默认行为。
- 目标 5：保证预览展示遵循用户现有的访问范围，不扩大数据可见性。

### 1.4 顶层产品约束

- **约束 1：保留官方默认行为**
  → 含义：未使用增强能力的 Many2one 不得产生可观察的行为变化。
- **约束 2：沿用原有打开关联记录入口**
  → 含义：不增加重复的查看入口，不改变用户对 Many2one 的基本操作认知。
- **约束 3：Extend 必须持续同屏**
  → 含义：当前业务区域和关联记录预览必须同时可见，不能用覆盖式弹窗冒充同屏。
- **约束 4：Extend 只读**
  → 含义：预览只负责查看，修改、保存、创建、删除和复杂业务操作必须进入完整记录页面。
- **约束 5：一个页面只保留一个 Preview Pane**
  → 含义：后打开的预览替换前一个预览，不同时并列多个预览。
- **约束 6：一个模型一套 Preview Configuration**
  → 含义：MVP 不引入同一模型的多套配置、场景 Profile、用户个人配置或配置优先级。
- **约束 7：不扩大权限**
  → 含义：管理员的展示配置不能让普通用户看到其原本无权查看的数据。

## 2 产品定位与上下文

### 2.1 能力类型

公共工具能力，面向需要增强关联记录查看体验的业务页面。

### 2.2 使用主体

- 普通业务用户：使用 `tab` 或 `extend` 查看关联记录。
- Preview 配置管理员：维护模型预览配置及字段顺序。

### 2.3 服务范围

全局通用，但只有明确使用增强能力的 Many2one 字段才改变其关联记录查看方式。

### 2.4 复用范围

- 可被不同业务域的 Many2one 字段复用。
- Preview Configuration 按目标模型维护，不绑定某一个具体业务页面。
- MVP 不支持按调用方、业务场景或个人维护多套配置。

### 2.5 上下游关系

| 方向 | 对象 | 关系说明 |
|---|---|---|
| 上游（调用方） | 使用 Many2one 的业务页面 | 提供当前业务记录和关联记录查看场景 |
| 下游（被调用） | Odoo 原有关联记录页面 | 在用户需要完整处理时承接完整记录查看和业务操作 |

### 2.6 依赖方向

- 本能力应作为通用查看能力，不感知调用方的具体业务语义。
- 调用方决定哪些 Many2one 字段使用增强能力。
- 完整关联记录的业务逻辑、操作范围和权限由原有 Odoo 业务能力决定。
- 本能力不得反向改变关联模型的业务规则。

## 3 范围

### 3.1 本期范围（In Scope）

- `tab`：在新浏览器标签页打开完整关联记录。
- `extend`：在当前页面右侧持续显示关联记录 Preview Pane。
- 沿用 Many2one 原有的打开关联记录入口。
- 当前业务区域和 Preview 持续同屏，Preview 不覆盖主要业务内容。
- 单 Preview Pane，后触发的预览替换前一个预览。
- Preview 只读。
- Model Preview Configuration。
- 一个模型一套 Preview Configuration，该配置可启用或停用。
- 预览字段选择和展示顺序维护。
- 基础业务字段的人类可读展示。
- 当前用户无权读取的字段不在 Preview 中展示。
- 无可用详细配置时提供基础降级展示。
- Many2one 值变化后同步更新 Preview。
- Many2one 清空后清除 Preview。
- 用户主动关闭 Preview。
- 从 Preview 进入完整关联记录。
- 遵循原有权限和业务规则。

### 3.2 明确排除（Out of Scope）

- 修改或重写 Odoo 官方 Many2one 默认行为。
- 独立的 `official` 模式。
- Many2one 高级选择器、搜索或候选筛选能力。
- 多 Preview Profile、场景 Profile、Default Profile。
- 用户个人 Preview 配置。
- Preview 内编辑、保存、创建、删除或复杂业务按钮。
- 在 Preview 中嵌入完整可编辑 Form。
- 双 Form 编辑、保存或放弃。
- Tooltip、Hover Preview、Modal Preview。
- 覆盖式 Drawer 或 Offcanvas。
- Preview 页面设计器。
- 多 Preview Pane 同时并列显示。
- 通用 Split View 框架。
- 强制支持 Preview 宽度拖拽调整。

### 3.3 后续版本候选

| 版本 | 候选能力 |
|---|---|
| 待定 | 多 Preview Profile |
| 待定 | 用户个人 Preview 配置 |
| 待定 | Preview 宽度自定义 |
| 待定 | 更复杂的响应式降级布局 |

只有真实业务证明单模型单配置明显不足时，才重新评审上述候选能力。

## 4 角色与权限

### 4.1 角色定义

| 角色编码 | 角色名称 | 职责描述 |
|---|---|---|
| ROLE-M2O-01 | 业务用户 | 在业务页面使用 `tab` 和 `extend` 查看关联记录，并继续处理当前业务记录 |
| ROLE-M2O-02 | Preview 配置管理员 | 建立、维护、启用、停用模型 Preview Configuration 及其字段顺序 |

### 4.2 权限矩阵

| 角色 | 使用 Tab | 使用 Extend | 查看 Preview 配置结果 | 维护 Preview 配置 | 修改 Preview 中的关联记录 |
|---|:---:|:---:|:---:|:---:|:---:|
| ROLE-M2O-01 | √ | √ | √ | × | × |
| ROLE-M2O-02 | √ | √ | √ | √ | × |

说明：

- 角色能否查看或操作完整关联记录，仍遵循其原有业务权限。
- Preview 配置管理员拥有配置维护职责，不因此获得额外的关联记录数据权限。

### 4.3 数据隔离规则

- 业务用户只能查看其原有权限范围内的关联记录。
- Preview 只展示当前用户有权读取的字段和值。
- 配置管理员配置的字段不得扩大任何用户的访问范围。
- 当前用户无权访问整条关联记录时，不得展示该记录名称、字段值或其他关联信息，只提供安全的无权查看提示。
- 当前用户无权读取某个字段但有权访问整条关联记录时，仅省略该字段，其他可读字段继续展示。

## 5 功能需求

### 5.1 原生行为与统一入口

#### FR-M2O-01 保持未增强 Many2one 的默认行为

**触发条件：** Many2one 字段未使用本项目的增强能力。

**业务行为：** 用户按照原有方式选择、清空或打开关联记录。

**业务结果：** 该字段的关联记录查看行为与 Odoo 官方默认行为一致。

**异常 / 边界：** 本能力不得向未增强字段增加新的查看入口，也不得改变其原有记录选择、清空、打开或权限行为。

#### FR-M2O-02 沿用原有打开关联记录入口

**触发条件：** 用户在使用增强能力的 Many2one 字段上触发打开关联记录入口。

**业务行为：** 系统根据该字段的增强模式执行 `tab` 或 `extend` 行为。

**业务结果：** 用户通过原有操作心智进入对应的关联记录查看方式。

**异常 / 边界：** 系统不得为同一查看目的增加重复的业务入口；选择、清空及其他标准操作不因增强能力而改变。

### 5.2 Tab 模式

#### FR-M2O-03 在新标签页打开完整关联记录

**触发条件：** 用户触发配置为 `tab` 模式的 Many2one 打开关联记录入口。

**业务行为：** 系统在新的浏览器标签页打开该关联记录的完整 Odoo 业务页面。

**业务结果：** 当前业务页面保持不变，新标签页提供正常完整记录查看和适用的业务操作入口。

**异常 / 边界：** 新标签页不得仅显示孤立字段内容；用户能否操作完整记录仍由其原有权限和业务规则决定。

### 5.3 Extend 模式

#### FR-M2O-04 打开只读关联记录 Preview

**触发条件：** 用户触发配置为 `extend` 模式的 Many2one 打开关联记录入口。

**业务行为：** 系统在当前页面右侧显示关联记录 Preview Pane。

**业务结果：** 当前业务区域和关联记录关键字段持续同时可见，用户可以继续查看和操作当前业务页面；当前 Preview 来源明确对应触发本次查看的 Many2one 字段。

**异常 / 边界：** Preview 不得覆盖当前业务区域的主要内容，不得以 Modal、Tooltip 或覆盖式 Drawer 代替持续同屏。当可用显示区域不足以合理维持持续同屏时，系统不得通过覆盖当前主要业务区域的方式强行展示 Extend，具体安全降级方式由后续设计确定。

#### FR-M2O-05 保持 Preview 只读

**触发条件：** 用户在 Preview Pane 中查看关联记录。

**业务行为：** 系统提供关联记录关键字段的查看结果。

**业务结果：** 用户可以阅读 Preview，但不能在 Preview 中修改、保存、创建、删除关联记录或执行复杂业务按钮。

**异常 / 边界：** 需要进一步处理关联记录时，用户必须通过“打开完整记录”在新浏览器标签页进入正常关联记录页面；当前业务页面及 Preview 状态保持不变。

#### FR-M2O-06 单 Preview Pane 替换

**触发条件：** 当前页面已经存在 Preview Pane，用户再次通过另一个 `extend` Many2one 触发关联记录查看。

**业务行为：** 系统关闭当前 Preview 内容并显示后触发的关联记录。

**业务结果：** 当前页面始终只保留一个 Preview Pane，内容对应最后一次触发的关联记录；当前 Preview 来源切换为最后一次触发的 Many2one 字段。

**异常 / 边界：** MVP 不提供多个 Preview Pane 并列显示。

### 5.4 Preview Configuration

#### FR-M2O-07 管理员维护模型预览配置

**触发条件：** Preview 配置管理员需要为某个关联模型定义预览内容。

**业务行为：** 管理员建立、查看、修改、启用或停用该模型的 Preview Configuration，并选择需要展示的字段及其顺序。

**业务结果：** 使用该模型的 `extend` 预览按照该模型唯一的 Preview Configuration 展示；配置可通过启用或停用控制是否提供详细字段。

**异常 / 边界：** 普通业务用户不得修改 Preview Configuration；同一模型在 MVP 中只能存在一套 Preview Configuration，不得通过创建多套停用配置保留候选或历史配置。

#### FR-M2O-08 按配置顺序展示预览字段

**触发条件：** 目标模型存在已启用且至少配置一个可展示字段的 Preview Configuration。

**业务行为：** 系统按照配置管理员设定的字段顺序展示关联记录信息。

**业务结果：** Preview 字段顺序与当前启用且包含可展示字段的配置一致，字段以业务可读名称和业务可读值呈现。

**异常 / 边界：** 当前用户有权访问关联记录但无权读取某个配置字段时，该字段不展示；如果用户无权访问整条关联记录，则按 BR-M2O-13 处理；不得用数据库标识或技术存储值替代业务展示值。

#### FR-M2O-09 无可用详细配置时降级展示

**触发条件：** `extend` 目标模型没有 Preview Configuration，配置已停用，或配置已启用但没有任何可展示字段。

**业务行为：** 在用户有权访问整条关联记录的前提下，系统展示当前关联模型、当前关联记录名称、缺少详细配置的提示和打开完整记录入口。

**业务结果：** 用户仍能识别当前关联记录并进入完整记录页面。

**异常 / 边界：** 如果用户无权访问整条关联记录，不得展示模型名称、记录名称或其他记录信息，只提供安全的无权查看提示。配置缺失不得导致 Extend 报错、页面不可用或影响当前业务页面继续操作。

### 5.5 关联值和 Preview 生命周期

#### FR-M2O-10 关联记录变化后同步更新

**触发条件：** 当前 Preview 来源 Many2one 字段的关联记录从一条记录变更为另一条记录。

**业务行为：** 系统更新已打开的 Preview 内容；页面中其他 Many2one 字段的值变化不触发当前 Preview 更新。

**业务结果：** 如果用户有权访问新关联记录，Preview 显示新的关联记录，不得继续显示旧记录；如果用户无权访问新关联记录，则只提供安全的无权查看提示。

**异常 / 边界：** 关联记录变化不得修改 Preview 之外的业务数据；如果新记录不可访问，则按 BR-M2O-13 处理。

#### FR-M2O-11 清空关联记录后清除 Preview

**触发条件：** 当前 Preview 来源 Many2one 字段被清空。

**业务行为：** 系统清除当前 Preview 内容；页面中其他 Many2one 字段被清空不影响当前 Preview。

**业务结果：** 页面不再显示已解除关联的旧记录信息。

**异常 / 边界：** 清空 Many2one 不得删除关联记录，也不得修改其他业务数据。

#### FR-M2O-12 主动关闭 Preview

**触发条件：** 用户主动关闭 Preview Pane。

**业务行为：** 系统关闭 Preview Pane。

**业务结果：** 当前业务页面继续可用，Many2one 值、当前业务记录和关联记录均保持不变。

**异常 / 边界：** 关闭 Preview 不得触发保存、修改、创建或删除业务数据。

#### FR-M2O-13 从 Preview 打开完整记录

**触发条件：** 用户认为 Preview 信息不足，需要进一步查看或处理关联记录。

**业务行为：** 用户从 Preview 触发“打开完整记录”。

**业务结果：** 系统在新浏览器标签页进入正常的关联记录完整页面，当前业务页面及 Preview 状态保持不变，并继续遵循原有导航、业务操作和权限规则。

**异常 / 边界：** 该入口不得绕过用户原有权限，也不得将 Preview 变成可编辑表单。

### 6.1 业务异常 vs 基础设施异常

| 类型 | 含义 | 业务处理 |

## 7 状态与生命周期

本模块没有独立的业务单据状态。为明确 Preview 的业务可见性，定义当前页面中的 Preview 生命周期。

### 7.1 状态定义

| 状态 | 业务含义 | 可进入条件 | 可执行动作 |
|---|---|---|---|
| 未打开 | 当前页面没有显示关联记录 Preview | 页面初始状态、用户关闭 Preview 或当前 Preview 来源 Many2one 被清空 | 触发 `extend` 查看、继续操作当前业务页面 |
| 已打开 | 当前页面正在显示某条关联记录的只读 Preview，并明确记录当前 Preview 来源 Many2one | 用户触发 `extend`，且存在当前关联记录 | 查看 Preview、打开完整记录、关闭 Preview、更新来源记录对应的 Preview |

### 7.2 状态流转

| 当前状态 | 动作 / 条件 | 目标状态 | 关联需求 |
|---|---|---|---|
| 未打开 | 触发 `extend` 且存在关联记录 | 已打开 | FR-M2O-04 |
| 已打开 | 再次触发其他 `extend` 关联记录 | 已打开，来源和内容替换 | FR-M2O-06 |
| 已打开 | 当前 Preview 来源 Many2one 的关联记录发生变化 | 已打开，内容更新 | FR-M2O-10 |
| 已打开 | 页面中其他 Many2one 字段的关联记录发生变化 | 已打开，内容不变 | FR-M2O-10 |
| 已打开 | 当前 Preview 来源 Many2one 被清空 | 未打开 | FR-M2O-11 |
| 已打开 | 页面中其他 Many2one 字段被清空 | 已打开，内容不变 | FR-M2O-11 |
| 已打开 | 用户主动关闭 Preview | 未打开 | FR-M2O-12 |

### 7.3 禁止流转

- BR-M2O-03：Preview 状态不得进入可编辑、可保存的关联记录状态。
- BR-M2O-04：Preview 打开后不得通过覆盖当前主要业务区域来形成伪同屏。
- BR-M2O-05：Preview 打开后不得形成多个同时并列的 Preview Pane。
- BR-M2O-10：当前 Preview 来源 Many2one 被清空后不得继续保留旧关联记录 Preview；其他 Many2one 被清空不得关闭当前 Preview。

## 8 配置需求

### CFG-M2O-01 模型 Preview Configuration

| 配置项 | 业务含义 | 默认值 | 生效范围 |
|---|---|---|---|
| 目标模型 | 指定哪一种关联模型使用该预览配置 | 无配置 | 对应目标模型的所有使用 `extend` 的字段 |
| Active | 控制该模型配置是否生效 | 未配置时无可用详细配置 | 当前目标模型 |
| Preview Fields | 指定 Preview 中需要展示的业务字段 | 空；启用但为空时无可用详细配置 | 当前目标模型 |
| Sequence | 指定字段展示顺序 | 按管理员设置；未设置时不承诺业务顺序 | 当前目标模型 |

### CFG-M2O-02 查看模式

| 配置项 | 业务含义 | 默认值 | 生效范围 |
|---|---|---|---|
| 查看模式 | 指定增强字段使用 `tab` 或 `extend` | 未启用增强能力时保持官方默认行为 | 被配置使用增强能力的 Many2one 字段 |

### 8.1 配置业务规则

- 同一模型在 MVP 中只能存在一套 Preview Configuration，该配置可启用或停用。
- 配置停用，或配置启用但 Preview Fields 为空时，使用该模型的 `extend` 必须按 BR-M2O-09 降级。
- 配置字段顺序只影响 Preview 的展示顺序，不改变关联记录业务数据。
- Preview Configuration 不是权限配置，不能扩大数据访问范围。
- 未使用增强能力的 Many2one 不受配置影响。

## 附录 A 术语表

| 术语 | 定义 |
|---|---|
| Many2one | Odoo 中用于选择和关联另一条业务记录的字段能力 |
| 关联记录 | 当前业务记录通过 Many2one 关联到的另一条业务记录 |
| `tab` | 在新的浏览器标签页打开完整关联记录的查看模式 |
| `extend` | 在当前业务页面右侧持续显示关联记录关键字段的查看模式 |
| Preview Pane | 当前页面中用于只读展示关联记录关键字段的区域 |
| 当前 Preview 来源 Many2one | 最近一次触发当前 Preview 的 Many2one 字段；只有该字段的关联值变化或清空会更新或关闭当前 Preview |
| Preview Configuration | 按目标模型定义 Preview 字段、启用状态和展示顺序的业务配置 |
| 完整记录页面 | Odoo 中用于查看或处理关联记录的正常业务页面 |
| 持续同屏 | 当前业务区域和关联记录 Preview 同时可见，且 Preview 不覆盖当前主要业务内容 |

## 附录 B 业务决策记录

| 决策编号 | 决策 | 原因 | 影响范围 |
|---|---|---|---|
| BD-01 | 不改变未增强 Many2one 的官方默认行为 | 降低对现有业务的影响，保留用户原有操作心智 | FR-M2O-01、BR-M2O-01 |
| BD-02 | Tab 和 Extend 共用原有打开关联记录入口 | 避免增加重复入口和新的操作认知负担 | FR-M2O-02、BR-M2O-02 |
| BD-03 | Extend 只读，不在 Preview 中提供业务写入 | 降低误操作风险，将完整业务处理留在标准记录页面 | FR-M2O-05、BR-M2O-03 |
| BD-04 | MVP 采用一个模型一套 Preview Configuration，该配置可启用或停用 | 先验证公共字段集合是否足够，避免过早引入 Profile 复杂度 | FR-M2O-07、BR-M2O-06 |
| BD-05 | 同一页面只保留一个 Preview Pane | 保持页面结构清晰，避免多个预览造成信息拥挤 | FR-M2O-06、BR-M2O-05 |
| BD-06 | 无配置时提供基础降级展示 | 配置缺失不应破坏关联记录查看能力 | FR-M2O-09、BR-M2O-09 |
| BD-07 | 无权读取的字段只隐藏，不阻断整个 Preview | 遵循权限边界，同时尽量保留可用信息 | FR-M2O-08、BR-M2O-08 |
