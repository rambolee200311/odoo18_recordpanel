## Included baseline

- Native Many2one behavior remains unchanged unless explicitly configured.
- `tab` opens the authorized related record in a new standard Odoo tab.
- `extend` provides one page-scoped, read-only related-record Preview.
- Preview uses current-user access semantics and safe DTO states.
- Stale page/request responses are discarded.
- CC-04 Chatter-aware layout is included:
  - wide: Business Form and Preview side by side, Chatter below the Form;
  - narrow: Business Form → Preview → Chatter.
- CC-05 hardens configuration changes, missing records, relation display
  values, loading close, and safe load-error presentation.

## Boundary

The release contains no SPIKE-02 runtime dependency, `stock` dependency,
business `sudo()`, raw SQL, DB driver, HTTP Controller, Preview cache,
editable Preview, multiple Preview panes, generic Split View, or Odoo
official-source modification.
